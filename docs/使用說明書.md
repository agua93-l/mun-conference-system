# MUN 線上會議系統 使用說明書

正式網址：**https://mun-conference-system.vercel.app**

這是一套給模擬聯合國（MUN）會議主席團使用的線上控制台。主席用它管理點名、發言名單、動議、計時器、文件與各種表決，並把畫面即時同步投影給代表看。系統的特點：

- **一個帳號可以管理多場會議**，適合不同委員會、不同屆次重複使用。
- **多位主席可以共同編輯同一場會議**，主席團分工操作。
- **代表用網址就能看投影畫面與文件庫，完全不需要登入或帳號。**
- **支援不同委員會的議事規則**（安全理事會 / 經濟及社會理事會）。

## 一、名詞與角色

| 角色 | 需要登入？ | 用途 |
|---|---|---|
| **主席（擁有者 / 共同編輯者）** | 需要 | 操作主席控制台，管理整場會議 |
| **代表** | 不需要 | 用主席給的網址看投影畫面、文件庫 |

| 頁面 | 網址 | 誰用 |
|---|---|---|
| 我的會議 | `/` | 主席 |
| 主席控制台 | `/chair/:會議代碼` | 主席 |
| 會議設定 | `/chair/:會議代碼/settings` | 主席 |
| 各國統計 | `/stats/:會議代碼` | 主席 |
| 代表投影畫面 | `/screen/:會議代碼` | 代表（免登入） |
| 文件庫 | `/docs/:會議代碼` | 代表（免登入） |
| 加入共同編輯 | `/join/:會議代碼` | 受邀請的其他主席 |

> 「會議代碼」是系統為每場會議產生的一串亂碼，不同會議代碼互相獨立、資料不會混。

## 二、註冊與登入

1. 打開網址，會看到登入畫面。
2. 第一次使用點下方「**還沒有帳號？註冊一個**」，輸入 Email、密碼（至少 6 碼），按「**註冊並登入**」。
3. 成功後自動進入「我的會議」頁面。
4. 之後登入直接輸入同一組 Email／密碼即可。

> **同一組帳號可以在多台電腦同時登入使用**，看到的是同一份會議清單，操作也會即時互相同步——適合主席團用不同電腦分工。

## 三、我的會議（儀表板）

登入後的第一個畫面，就是你的會議清單：

- **建立新會議**：上方輸入框填標題（例如「NSTMUN 2026 經社理事會」），按「➕ 新增會議」，會自動進入這場會議的主席控制台。
- **切換會議**：下方列出你建立或受邀的所有會議，點卡片即可進入。
- 每張卡片右下角有標籤：**擁有者**（你建立的）或 **共同編輯**（別人邀你加入的）。
- 每場會議的代表清單、議程、點名、動議、文件、統計都是**互相獨立**的。

## 四、會議設定

主席控制台右上角的 **⚙️（設定）** 圖示進入。可編輯：

### 會議標題
顯示在主席控制台頂端、代表投影畫面、瀏覽器分頁標題，隨時可改。

### 代表／國家清單
- 新增：填國家／代表名稱，選「理事國（member）」或「觀察員（observer）」，理事國可再勾「P5」（僅安理會模式有意義）。
- 刪除：清單旁的垃圾桶。若該國已有統計資料，會提示但仍可刪。
- 新建會議預設帶入一份 19 國範例清單，可整份刪光重編。

### 議程時間表
- 新增／刪除議程項目（純文字，例如「議程 1 (5/30 09:30~11:30)」）。
- 主席控制台上方的議程下拉選單會顯示這裡設定的項目。

### 委員會規則 ⭐（新功能）
選擇這場會議套用哪一套議事規則，會影響表決的通過標準與投票選項：

| 規則 | 實質表決（決議草案／修正案）通過標準 | 否決權 | 唱名決投票選項 |
|---|---|---|---|
| **安全理事會** | 贊成 ≥ 9 票且無 P5 否決 | 五常（P5）有否決權 | 贊成／贊成並發言／反對／反對並發言／棄權／跳過 |
| **經濟及社會理事會** | 簡單多數（贊成 > 反對，棄權不計） | 無 | 以上再加「棄權並發言」 |

選單旁會即時顯示所選規則的重點說明。切換後，唱名表決的通過判定、投影畫面上未通過的原因文字、投票彈窗的可選項目，都會跟著改變。

### 共同編輯（見下一節）

> 編輯完記得按最下方「💾 儲存設定」。

## 五、多位主席共同編輯

在「會議設定」的「共同編輯」區塊：

1. **主席（擁有者）**：複製「邀請連結」（形如 `.../join/會議代碼`），傳給要一起主持的其他主席。
2. **受邀主席**：用自己的帳號登入後打開這個連結，按「✅ 加入共同編輯」即可。
3. 加入後，共同編輯者**權限與擁有者完全相同**：可以操作控制台、改設定、甚至再邀請別人。
4. 這個區塊會列出目前所有共同編輯者。
5. 共同編輯者可以按「🚪 退出這場會議的共同編輯」自行退出（擁有者看不到這顆按鈕，不會誤退出）。

> 所有主席的操作都即時同步——一個人點名、另一個人同時管動議，畫面會互相反映。

## 六、主席控制台

開會期間主席主要操作的畫面（`/chair/:會議代碼`）。

### 頂部工具列
- **會議標題**與目前**會議階段**標籤。
- 右上角圖示：**⚙️ 設定**、**📋 我的會議**、**🚪 登出**。
- 第二排：
  - **議程下拉選單**：切換目前議程。
  - **📺 代表端**：另開分頁顯示投影畫面（給投影機／代表）。
  - **📚 文件庫**：另開分頁顯示公開文件庫。
  - **📊 統計**：查看各國統計表。
  - **⏸️ 暫停 / ▶️ 恢復**、**✅ 返回辯論**：控制會議流程狀態。
  - **⋯（更多）**：收納不常用／危險操作——💾 儲存進度、🗑️ 清除統計、⚠️ 重置會議（會二次確認）。

### 常設發言人名單
- 設定預設發言時長（秒）。
- 選國家「加入名單」排入發言序。
- 「➡️ 下一位」輪替發言人，「▶️ 開始／⏸️ 暫停」控制計時。
- 「🔄 讓渡予...」把剩餘時間讓給另一位代表。

### 點名系統
- 「📢 開始點名」啟動後，逐一點名理事國「出席／遲到／缺席」（出席可再改遲到）。
- 全部點完自動顯示出席統計與投票門檻（簡單多數、絕對多數 2/3、1/5 提議門檻）。

### 動議佇列
- 選動議類型、動議國，填必要細節後「📥 提交動議」。動議會自動依議事規則優先級排序。
- 動議類型與所需欄位：
  - **自由磋商／全體諮詢**：時長（分）。
  - **有主持核心磋商**：主題、總時長（分）、每人發言（秒）。
  - **唱名表決／共識決**：表決議題（例如「決議草案 DR 1.1」）。
  - 暫停會議／恢復會議／P5閉門協商等：無額外欄位。
- 主席對佇列中的動議「✓ 通過」或「✗ 駁回」。
- 通過後按「📢 執行當前表決動議」正式啟動（進入磋商計時、唱名表決、共識決等）。

### 文件上傳與審核（見下一節）

### 發言紀錄
- 有發言人時，主席可針對「目前發言人」輸入紀錄／評語，按「➕ 加入」。**這份紀錄只有主席看得到，不會出現在投影畫面。**

### 各國統計（小面板）
即時顯示各國發言次數與動議成功次數，完整版在統計頁。

### 有主持核心磋商控制（進入該模式才出現）
加入特設發言名單、控制發言順序與雙計時器（總時長／單人發言）。

## 七、文件與表決流程 ⭐（新功能）

### 文件類型
主席在「文件上傳與審核」區塊上傳三種文件：

| 類型 | 說明 |
|---|---|
| **工作文件（WD）** | 輔助討論的文件 |
| **潛在決議草案（DR）** | 尚未經表決的決議草案，通過介紹表決後升級為「正式決議草案」 |
| **修正案（A）** | 對某份決議草案的修改 |

### 上傳修正案的結構化欄位
選「修正案」時，除了編號、標題，還要填：
- **目標決議草案**（從已審核的草案中選）
- **提案國**（選填）
- **條款**（例如 OP3、PP2）
- **修改類型**（新增／修改／刪除）
- **修改內容**（新增或修改後的完整條款文字，或說明刪除範圍）
- **檔案為選填**——投影與文件庫會直接顯示上面填的結構化內容，不需要開檔案才看得到改了什麼。

### 審核
上傳的文件預設「⏳ 待審」，主席按「✓ 通過」後才會出現在代表文件庫；「✗ 退回」則不公開。

### 介紹表決（修正案／潛在決議草案）
1. 已審核的修正案或潛在決議草案，清單上會出現「📢 介紹表決」按鈕。
2. 按下後：
   - **代表端投影**大字顯示表決內容（修正案會秀出目標草案、條款、修改類型、修改內容全文）。
   - **主席端**左欄出現表決控制面板（同樣內容 + 通過／不通過／取消）。
3. 主席記錄結果：
   - 修正案 → 標記為通過／未通過（文件庫會顯示結果標籤）。
   - **潛在決議草案通過 → 自動升級為正式決議草案**，文件庫分類跟著移動。

## 八、代表端頁面（投影／文件庫）

兩個頁面都**不需要登入**，主席把連結分享給代表或投影電腦即可。同一場會議可以同時開很多分頁，畫面都即時同步。

### 投影畫面（`/screen/:會議代碼`）
從主席控制台「📺 代表端」取得連結。會依主席端目前狀態自動切換畫面：
- 點名進行中（含出席統計與門檻）
- 唱名表決（含議題、逐國票態、結果與未通過原因）
- 共識決（含議題、結果）
- 修正案／潛在決議草案介紹表決（大字顯示修改內容）
- 自由磋商／全體諮詢倒數、有主持核心磋商、P5 閉門、會議暫停
- 預設：常設發言人名單 + 點名統計 + 場上已通過文件

### 文件庫（`/docs/:會議代碼`）
從主席控制台「📚 文件庫」取得連結。分組顯示所有已審核公告的文件：
- **決議草案**（正式）
- **潛在決議草案**
- **修正案**（附提案國、目標草案、條款、修改類型、修改內容全文，以及表決結果標籤）
- **工作文件**

有附檔的文件顯示下載按鈕。主席公告新文件後即時更新。

## 十、常見問題

**Q：代表需要註冊帳號嗎？**
不用。代表只要拿到主席給的投影畫面連結（`/screen/...`）或文件庫連結（`/docs/...`）就能看，完全不需要登入。

**Q：我換了一台電腦，會議資料還在嗎？**
在。資料存在雲端，用同一組帳號在任何裝置登入都看得到同一份會議清單。

**Q：兩位主席可以同時操作同一場會議嗎？**
可以。用「共同編輯」邀請連結加入後，多位主席的操作會即時互相同步。

**Q：「重置會議」會刪掉什麼？**
會清空點名、投票、動議、統計、文件、發言紀錄等「進行中」的資料，但**不會動到標題、代表清單、議程、委員會規則等設定**。此動作無法復原，會二次確認。

**Q：切換委員會規則（安理會／經社理事會）會怎樣？**
會改變唱名表決的通過標準（安理會 9 票+否決 vs 經社理事會簡單多數）、投影上未通過的原因文字，以及投票彈窗的可選項目（經社理事會多「棄權並發言」）。

## 十一、測試檢查清單（給測試的人）

麻煩照順序走一遍，發現哪一步跟預期不一樣，記下「第幾項＋看到什麼」回報：

- [ ] 註冊新帳號，確認能進到「我的會議」
- [ ] 建立一場新會議
- [ ] 進「設定」：改標題、加／刪代表、加議程項目、切換委員會規則，儲存後回控制台確認有更新
- [ ] 開始點名，標幾個國家出席／遲到／缺席，全點完確認門檻數字出現
- [ ] 另開分頁貼上「代表端」網址，確認畫面跟主席端同步（點名狀態一致）
- [ ] 常設發言人名單：加國家、開始計時、下一位、試讓渡
- [ ] 提交「自由磋商」10 分鐘，通過並執行，確認代表端進入磋商倒數
- [ ] 上傳一份潛在決議草案（附小檔案），審核通過
- [ ] 上傳一份修正案（填目標草案／條款／修改內容，不附檔），審核通過
- [ ] 對修正案點「介紹表決」，確認代表端投影大字顯示修改內容，記錄通過，確認文件庫顯示「已通過」
- [ ] 對潛在決議草案點「介紹表決」記錄通過，確認它升級成正式決議草案（文件庫分類移動）
- [ ] 開「文件庫」網址（不登入），確認四類文件分組正確、下載連結可用
- [ ] 提交「唱名表決」動議（填議題），執行後確認投影顯示議題；投幾票後「結束投票」確認結果與通過判定正確
- [ ] 切成「經濟及社會理事會」規則，唱名表決確認投票彈窗多出「棄權並發言」，且 2 贊成 1 反對能通過（簡單多數）
- [ ] 開「各國統計」，確認數字正確，「匯出 Excel」檔案能開
- [ ] （多人測）用邀請連結讓第二個帳號加入共同編輯，確認雙方都能操作、退出後失去權限
- [ ] 登出重新登入，確認「我的會議」清單裡看得到剛建立的會議

有任何一步卡住、跳錯誤、或跟說明不一樣，麻煩截圖＋描述當下操作步驟回報。
